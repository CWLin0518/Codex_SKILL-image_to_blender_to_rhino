# 商品圖到 Blender 與 Rhino 的工作流程

## 任務設定

- Blender 建模單位使用公尺；Rhino 交付單位使用毫米。
- 預設交付保留部件和基本材質配色的網格模型。
- 尺寸圖優先；照片用於補充形狀、比例、結構與細節。
- 未提供的尺寸依照片合理推估，寫入 `MODEL_NOTES.md`，不得宣稱為原廠精確尺寸。
- 建議座標為 X 寬、Y 深、Z 向上，並記錄模型正面方向。

## 前置檢查

1. 列出輸入路徑中的檔案，查看全部相關商品圖、細節圖和尺寸圖。
2. 檢查 Blender MCP addon、版本與目前場景，不假設場景為空。
3. 檢查 Rhino MCP 可用 slots 與文件內容，優先使用合適的既有實例；必要時嘗試建立新實例。
4. 查閱本次實際使用的匯出／匯入 API 與 enum，不硬編碼尚未確認的版本選項。
5. 向使用者簡短說明主要尺寸、推估部位與交付類型。

若工具或連線不可用，回報具體原因並繼續可完成的工作。Blender MCP safe mode 禁止 `open`、`exec` 或 `os` 時，使用允許的直接建模指令與原生儲存／匯出 operator，不繞過安全限制。

## 圖片判讀

整理主體輪廓、部件數量、結構關係、材質和辨識特徵。家具常見項目包括底座、坐墊、靠背、扶手、支架、腳、接縫、滾邊、固定帶和鈕扣。

分別解讀總寬、總深、總高、座高、座深和背寬。不要把座深當成總深。不確定的值標為推估。

## Blender 建模

1. 建立以模型名稱命名的專用 collection，使用清楚、穩定的部件名稱。
2. 先建立符合主要尺寸的主體，再增加輪廓、圓角、厚度、傾角和細節。
3. 軟墊與布面應有合理弧度；滾邊貼合表面，不得浮空、穿插或明顯重疊。
4. 建立基本材質與配色。程序紋理可補充布料外觀，但模型辨識不能依賴程序紋理。
5. 以節點類型查找 shader，不依賴受語系影響的顯示名稱。
6. 控制網格密度，兼顧輪廓和可操作性，保留有意義的部件分離。
7. 查看正面、側面、背面與必要細節，並取得場景資訊確認物件存在。
8. 修正比例、接縫、法線和缺件後儲存 `.blend`。

保留可重現的建模腳本，最終修正也要同步寫回腳本。若腳本與 safe mode 的執行方式不同，在說明中記錄使用方式。

## 匯出與交接

Blender 檢查完成後，交接以下資訊：輸出路徑、collection 名稱、預期部件數、Blender 單位、座標方向與正面方向。要求後段工作只匯出本次 collection，包含曲線實體化後的可見幾何與 modifier 結果，並保留名稱、部件和基本材質。

使用 Blender 原生匯出 operator 產生 OBJ 與 MTL：

1. 僅匯出指定 collection／選取物件，排除預設立方體、相機、燈光及無關物件。
2. 確認曲線、支架、滾邊與細節已轉成 evaluated mesh 並被匯出。
3. 明確設定並記錄座標軸和比例，防止鏡射、倒置或重複縮放。
4. 檢查 OBJ 部件結構。OBJ 可能以 `g` 而不是 `o` 記錄部件，同一部件也可能多次切換群組；自行解析時要正確合併，防止漏面、重複幾何和空群組。
5. 確認 MTL 存在，物件名稱與材質對應完整。

## Rhino 匯入與儲存

1. 明確指定 Rhino slot；腳本使用工具提供的 `__rhino_doc__`，不要依賴可能指向其他文件的 `ActiveDoc`。
2. 優先以可靠的原生流程匯入 OBJ；必要時解析 OBJ／MTL，建立 Rhino Mesh 和材質。
3. 從公尺轉毫米時將實際座標乘以 1000，且只做一次。不得只更改文件單位標籤。
4. 保留部件名稱，使用模型專用圖層，將材質明確指派到物件或圖層。
5. 檢查 mesh validity、法線、部件數、遺漏、重複和尺寸異常。
6. 設定合適視角與 Shaded／Rendered 顯示，確認模型可見。
7. 儲存 `.3dm`，避免納入無關物件。

## 獨立驗證 3DM

主代理直接讀取已儲存的 `.3dm`，不得只依賴後段代理的訊息或 Rhino 畫面。核對：

- 檔案存在、大小合理且可讀取。
- 文件單位為毫米。
- 部件數符合預期，合理拆分或合併須說明。
- 所有網格有效，法線無明顯異常。
- Bounding box 的寬、深、高符合尺寸圖或記錄的推估值。
- 名稱、圖層、材質表及物件／圖層材質指派都已寫入檔案。
- 特徵配色在轉檔後仍正確。

Rhino 工作階段存在材質不代表材質已存入 `.3dm`。若讀回後遺失，修正序列化、材質索引與指派，重新儲存並讀回。自建 `File3dm` 時，明確加入圖層、材質與物件，使用檔案內正確的材質索引。

若可直接用 `File3dm` 讀檔驗證，不必啟動新的 Rhino 實例。最後查看 Rhino 截圖，確認造型、方向和配色。若截圖包在文字 JSON 的巢狀 `content`，解析內容並顯示圖片，不要輸出大量 base64。

## 交付與說明

`MODEL_NOTES.md` 記錄尺寸依據、推估項目、座標與單位、部件說明、轉檔限制和最終實測尺寸。

完成回覆提供 `.3dm` 與 `.blend` 的完整可點擊路徑、有效物件數和尺寸，並說明：模型依商品照片與尺寸圖重建；未提供尺寸的細節採近似比例；Rhino 成品為網格模型，並非原廠精確 NURBS 或製造用 CAD；Blender 程序布紋未必能完整移轉，Rhino 版本以幾何和基本配色為交付重點。

持續執行到所需檔案完成且驗證通過。只有必要步驟受到外部條件阻擋時，才回報已完成成果、具體阻礙和需要的最小協助。不得將未驗證的檔案標示為完成。
